# Emmet Nedir?
Emmet, HTML ve CSS yazarken uzun etiketleri tek tek yazmak yerine kısa kısaltmalar kullanarak saniyeler içinde kod blokları oluşturmamızı sağlayan bir hızlandırma aracıdır.

## Temel Emmet Kodları ve Karşılıkları

| Emmet Kısaltması | Çıktı Sonucu | Açıklama |
|---|---|---|
| `!` | HTML5 iskeleti | Standart HTML yapısını (html, head, body) tek seferde oluşturur. |
| `div.kutu` | `<div class="kutu"></div>` | Class değeri "kutu" olan bir div açar. |
| `div#baslik` | `<div id="baslik"></div>` | ID değeri "baslik" olan bir div açar. |
| `ul>li*3` | `<ul>` içinde 3 tane `<li>` | İç içe 3 adet liste elemanı oluşturur. |
| `h1{Ödev}` | `<h1>Ödev</h1>` | İçinde metin yazan bir başlık oluşturur. |
| `a[href="link"]` | `<a href="link"></a>` | Hedefi (href) olan bir link etiketi oluşturur. |
